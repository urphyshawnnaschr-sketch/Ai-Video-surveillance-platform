request body示例

response body示例:

#2. 人脸检测

url: http://localhost:8003/detect

request body示例
{
"image":"",
"image_type":"BASE64"
}

response body示例
{
    "face_num":1
    "faces":[
        {
            "face_probability":0.95,
            "bbox":[xmin,ymin,xmax,ymax],
        }
    ]
}
注释:
+face_num: 人脸数量
+faces: 检测的人脸列表
++ face_probability: 人脸置信度
++ bbox: 人脸包围框位置

#3. 人脸识别

url: http://localhost:8003/recognize

request body示例
{
"image":"",
"image_type":"BASE64",
"camera_id":"1",                     
"capture_time":"2023-02-02-13-34-25-33"  # 格式不限定，是字符串就行，不要出现下划线
}

response body 示例：
{
    "face_num":1
    "faces":[
        {
            "face_probability":0.95,
            "similiarity":0.8
            "bbox":[xmin,ymin,xmax,ymax],
            "user_info":{
                "group_id":"china",
                "user_id":"1111",
                "face_id":"1"
            }
        }
    ]
}
+face_num: 人脸数量
+faces: 检测的人脸列表
++ face_probability: 人脸置信度
++ similiarity: 人脸匹配相似度
++ bbox: 人脸包围框位置
++ user_info: 匹配的人脸对应的用户信息,包含group_id,user_id,face_id

#4. 人脸库管理--查询用户组列表(query_group_list)
#5. 人脸库管理--查询用户列表(query_user_list)
#6. 人脸库管理--删除用户组(clear_group)
#7. 人脸库管理--删除用户(clear_user)
#8. 人脸库管理--删除用户人脸(clear_face)
4-8 参数类似，需根据具体操作类型选择设置group_id,user_id,face_id等,

url: http://localhost:8003/face_lib_manager

request body示例：
{
"op_type":"query_user_list"  
"group_id":"xxxxx"
}
response body示例:
{
"status":"success",
"user_list":user_list
}

import cv2  
import requests  
import json
import base64
import time


def test_detect_face():
    # 读取图像  
    image = cv2.imread('./test_images/mahuateng_2.jpg')  
    # 将图像转换为Base64编码的字符串
    _, img_encoded = cv2.imencode('.jpg', image)
    image_base64 = base64.b64encode(img_encoded).decode('utf-8')

    # 构造JSON请求体
    data = {
        'image': image_base64,
        "image_type":"BASE64"
    }
    json_data = json.dumps(data)

    # 发送HTTP请求
    url = 'http://localhost:8003/detect'
    headers = {'Content-Type': 'application/json'}

    response = requests.request("POST", url, headers=headers, data=json_data,stream=False)
    # 检查响应状态码
    if response.status_code == 200:
        print('图像成功发送到服务器！')
        data = json.loads(response.content)
        print(data)
    else:
        print('发送图像时出现问题。')
