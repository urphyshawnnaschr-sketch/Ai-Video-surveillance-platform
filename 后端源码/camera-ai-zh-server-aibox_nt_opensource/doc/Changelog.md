## 2025-07-16 V1.4.0
增加人脸服务管理相关功能

## Updated
- config.json文件增加两个字段
  use_type: 使用用途，0-表示只用于推理用途（默认），1-表示只用于人脸推理，2-表示推理+人脸推理；
  face_http_port: 人脸识别服务端口，默认是2024

### 2025-04-16 Release 1.3.0
本次属于重大更新，支持多种盒子设备，修复一些问题；<br/>
对于旧项目，请参考升级指南部分进行处理；<br/>
具体内容请参考文档说明：Changelog-2025-04-16.doc;

### Added
- 增加算法针对摄像头开启时，摄像头无法连接、摄像头无法获取帧、模型加载失败、加载成功等情况，提供http接口[/api/aibox/camera/report]给算法；
- 增加多种盒子算法管理支持，修改yml配置，proj-confs.platform为多种类盒子，例如"chaoxing,1684";

### Updated
- 修改盒子/服务器进行注册时，必须提交对应硬件芯片编码，如chaoxing,1684,1684x等；
- 修改算法编辑功能，增加多种盒子设备相关算法文件下载；
- 修改算法编辑功能，增加扩展参数支持；
- 修改模型导入功能，增加多种盒子设备的模型下载支持；
- 修改算法版本功能，增加多种盒子设备的模型切换操作；
- 修改摄像头关联算法时，根据盒子的硬件芯片进行算法关联；
- 修改卸载算法功能，删除服务器上的下载算法文件；
- 修改删除卡片功能，删除服务器上的下载算法文件；
- 修改卸载算法功能，删除盒子设备上的算法文件，但不重启；
- 修改删除卡片功能，删除盒子设备上的算法文件，但不重启；

### Deleted
- 删除前端界面共享模式的选择项，必须在init-data.sql进行预置；
- 删除前端界面硬件平台选择项；
- 删除“导入完整算法包”功能，点击新增算法直接跳转卡片新增界面；

### 升级指南
- yml文件变更，proj-confs.platform参数，单种盒子情况下无需修改；
- config.json必须增加chip参数，对应不同芯片，比如chaoxing,1684,1684x等；
- socket_interface.py需要升级；
- 检查盒子列表，查看芯片类型列是否有数据，如果没有，需要手动更新数据库，update tbl_biz_location set platform='芯片类型';
- 如果需要增加扩展参数，需要手动修改数据库，例如：update tbl_biz_algorithm set extras = '[{"name":"min_detect_frame_num","label":"最小连续帧检测次数","type":"number","value":"1","element":"input"}]' where name_en = 'people';
