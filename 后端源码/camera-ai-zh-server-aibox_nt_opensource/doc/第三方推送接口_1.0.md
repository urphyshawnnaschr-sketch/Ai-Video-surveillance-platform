# 接口规范
## 一、概述
本规范旨在定义和描述系统接口的相关要求和标准，确保接口的一致性

## 二、术语
无

## 三、推送接口定义
### 3.1 第三方通用报警和人脸报警数据推送接口
接口描述：将平台的报警数据推送到客户平台
#### 3.1.1 接口地址
接口地址：由客户提供接口地址，如`http://ip:port/alarm_data`
#### 3.1.2 请求方法
请求方法：post, application/json;
#### 3.1.3 请求参数
| 参数名                  | 类型 | 是否必传 | 描述                          |
|:---------------------| :- | :- |:----------------------------|
| pushType             | string | 是 | comm-通用算法报警，face-人脸报警       |
| cameraId             | string | 是 | 摄像头id                       |
| cameraName           | string | 是 | 摄像头名称                       |
| rtspUrl              | string | 是 | 摄像头流地址                      |
| algorithmId          | string | 是 | 算法id                        |
| algorithmName        | string | 是 | 算法名称                        |
| algorithmNameEn      | string | 是 | 算法编码                        |
| alarmAt              | string | 是 | 报警时间，格式:yyyy-MM-dd HH:mm:ss |
| params               | string | 是 | 报警识别数据，JSON字符串              |
| imgUrl               | string | 是 | 原图片URL                      |
| thumbImgUrl          | string | 是 | 缩量图片URL                     |
| boxSn                | string | 是 | 盒子序号                        |
| boxId                | string | 是 | 盒子id                        |
| boxIpAddr            | string | 是 | 盒子ip                        |
| boxName              | string | 是 | 盒子名称                        |
| alarm_count          | int | 是 | 报警数量                        |
| imageBase64          | string | 否 | 图片base64                    |

#### 3.1.4 响应参数
| 参数名 | 类型 | 描述 |
| :- | :- | :- |
| code | int | 响应状态码, 0-成功 500-失败 |
| msg | string | 响应描述 |
#### 3.1.5 请求示例
http://localhost:8080/alarm_data
```json
{
    "pushType": "comm",
    "cameraId": "1798024008527409154",
    "cameraName": "广场东南角",
    "rtspUrl": "rtsp://******:******@192.168.3.11/Streaming/Channels/101",
    "algorithmId": "1798196224430862338",
    "algorithmName": "行人检测",
    "algorithmNameEn": "people",
    "alarmAt": "2025-12-05 12:31:32",
    "params": "[{'type': 'people', confidence: 0.9, 'position': [100, 123, 524, 612]}]",
    "imgUrl": "http://localhost:8080/report/stream?id=1798024440280674306",
    "thumbImgUrl": "http://localhost:8080/report/streamThumb?id=1798024440280674306",
    "report_id": "1798024440280674306",
    "webUrl": "http://192.168.1.124:8021",
    "boxSn": "L200223C22A00094",
    "boxId": "1798024440280614575",
    "boxName": "test",
    "boxIpAddr": "192.168.1.115",
    "alarmCount": "1",
    "imageBase64": ""
}
```
#### 3.1.6 返回示例
```json
{
    "code": 0,
    "msg": "ok"
}
```

### 3.2 第三方视频报警数据推送接口_仅视频地址
接口描述：报警视频数据同步第三方平台, 适用于第三方平台不存储视频，仅通过URL调用查看视频；
#### 3.2.1 接口地址
接口地址：由客户提供接口地址，如`http://ip:port/video_url_data`
#### 3.2.2 请求方法
请求方法：post, application/json;
#### 3.2.3 请求参数
| 参数名             | 类型 | 是否必传 | 描述             |
|:----------------| :- | :- |:---------------|
| recordId        | string | 是 | 录像ID           |
| reportIds       | string | 是 | 报警ID列表,JSON字符串 |
| videoName       | string | 是 | 视频文件名称         |
| videoSize       | string | 是 | 视频文件大小         |
| videoExt        | string | 是 | 视频文件扩展名，如mp4   |
| videoUrl        | string | 是 | 视频地址URL        |

#### 3.2.4 响应参数
| 参数名 | 类型 | 描述 |
| :- | :- | :- |
| code | int | 响应状态码, 0-成功 500-失败 |
| msg | string | 响应描述 |
#### 3.2.5 请求示例
http://localhost:8080/video_url_data
```json
{
  "recordId": 123,
  "reportIds": "[123,234]",
  "videoUrl": "127.0.0.1:9000//123/4.mp4",
  "videoName": "4.mp4",
  "videoExt": "mp4",
  "videoSize": 33703
}
```
#### 3.2.6 返回示例
```json
{
    "code": 0,
    "msg": "ok"
}
```

### 3.3 第三方视频报警数据推送接口_仅视频文件
接口描述：报警视频数据同步第三方平台, 适用于第三方平台需要存储视频，通过上传视频文件到第三方平台；
#### 3.3.1 接口地址
接口地址：由客户提供接口地址，如`http://ip:port/video_file_data`
#### 3.3.2 请求方法
请求方法：post, application/form-data;
#### 3.3.3 请求参数
| 参数名       | 类型     | 是否必传 | 描述           |
|:----------|:-------| :- |:-------------|
| videoInfo | string | 是 | 录像信息，JSON字符串 |
| videoFile | file   | 是 | 录像文件对象       |

#### 3.3.4 响应参数
| 参数名 | 类型 | 描述 |
| :- | :- | :- |
| code | int | 响应状态码, 0-成功 500-失败 |
| msg | string | 响应描述 |
#### 3.3.5 请求示例
http://localhost:8080/video_file_data
```text
videoInfo: form-data
{"recordId":123,"reportIds":"[123,234]","videoName":"4.mp4","videoExt":"mp4","videoSize":33703}
videoFile: form-data
file对象
```
#### 3.3.6 返回示例
```json
{
    "code": 0,
    "msg": "ok"
}
```
